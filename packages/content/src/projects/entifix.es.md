entifix es un framework code-first para Clean Architecture y diseño guiado por el dominio. El dominio se escribe como código: una entidad es una clase que se describe a sí misma —sus miembros, sus tipos, cuáles se pueden filtrar u ordenar— y un caso de uso es una operación de negocio sobre entidades. No hay un archivo de esquema ni una configuración que mantener al día: el código es el modelo.

Todo lo demás rodea a ese dominio como un adaptador. Un caso de uso depende de un puerto —un repositorio, una sesión, un servicio de tokens—, nunca de una base de datos ni de un framework, así que el mismo caso de uso corre en el navegador sobre REST y en un servidor sobre Mongo o SQL; el adaptador se elige donde se compone la aplicación. La interfaz también es un adaptador, y un detalle de implementación: la misma descripción guía la tabla que lista una entidad y el formulario que la edita, y los controles de React son solo los primeros.

Se extrajo de un marketplace que lo impulsó durante un año, así que su código está probado; lo nuevo es su empaquetado en niveles independientes, cada uno adoptable sin los superiores. La implementación actual es TypeScript sobre Effect.
